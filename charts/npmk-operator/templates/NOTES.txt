## Create Your First Proxy Host

1. Create a DNS credentials secret (for Let's Encrypt):

   kubectl create secret generic cloudflare-credentials \
     --namespace=my-app-namespace \
     --from-literal=credentials='dns_cloudflare_api_token = YOUR_API_TOKEN'

2. Create an Npmko resource:

   cat <<EOF | kubectl apply -f -
   apiVersion: npmko.io/v1alpha1
   kind: Npmko
   metadata:
     name: my-app
     namespace: my-app-namespace
   spec:
     serviceName: my-app-service
     domainNames:
       - myapp.example.com
     ssl:
       enabled: true
       forceSSL: true
       dnsChallenge:
         provider: cloudflare
         credentialsSecretRef:
           name: cloudflare-credentials
   EOF

3. Check the status:

   kubectl get npmko -A
